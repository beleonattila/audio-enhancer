Rules of thumb

Typical order, top to bottom:

De-reverb→ Clean→ Restore→ Repair & mix→ Master
  1. De-reverb first, on the untouched recording: WPE, RoFormer, UVR DeEcho. Placed after other steps they barely find any reverb. Stereo RoFormer models need real stereo; mono files use the mono model.
  2. Then a filter-type cleaner: ClearerVoice SE, DeepFilterNet3 or FFT denoise. They only filter, so overlapping voices survive. One is usually enough.
  3. At most one generative step: Sidon, Separate + Sidon, resemble-enhance or VoiceFixer. Use Separate + Sidon when the hosts talk over each other.
  4. After a generative step: a light DeepFilterNet3 (8–15 dB) for leftover noise, then Dropout repair to bring back erased syllables.
  5. Mix for naturalness: 10–50 % of the input or of a filter-only step (e.g. ClearerVoice SE) hides gating, warble and the sterile sound.
  6. Master last, in this order: Tone EQ → De-esser → Expander → Compressor → Room → Loudness. Loudness is always the final step.

Workflow: select ~3 minutes in the ribbon and Cut, tune the pipeline on that snippet (unchanged steps come from cache), compare Input / Output, then Full file and run once more.
